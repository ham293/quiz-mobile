# 模块接口约定（所有开发者/子任务必读）

本项目是**手机端刷题助手**：静态网页（`web/`）+ Capacitor 打包成 Android APK。
**没有前端构建步骤**：`web/` 里的 HTML/CSS/JS 直接跑（CI 只负责 Cap + Gradle 打包）。
因此：全部使用**原生 ES Module**（`import`/`export`），不要引入打包器专属语法（不要 `import.meta.glob`、不要 `.vue`、不要 TypeScript）。

## 目录

## 通用规范

- 语言：注释与用户可见文案用中文；变量/函数名用英文小驼峰；常量用大写蛇形。
- 纯逻辑模块（`models/parser-text/ebbinghaus/stats/practice`）**必须能在 Node 里直接 import 并测试**：
  不许访问 `window` / `document` / `navigator`（`extract.js`、`exporter.js`、`ui/*` 除外）。
- 不许使用 CDN 或联网加载资源：APK 内必须离线可用，第三方库一律 vendor 到本地。
- 所有导出函数要有 JSDoc 注释（含参数与返回）。
- 不抛未捕获异常给 UI：解析/导出等易错环节返回结果对象或抛自定义错误，由调用方兜底。
- 测试用 `node:test` + `node:assert/strict`，放 `tests/*.test.mjs`，运行 `npm test`。

## 数据结构

### Question（普通对象，可直接存 IndexedDB）
```js
{
  qid: "a1b2c3d4e5f60718",   // sha1(normalizeStem(stem)).slice(0,16)
  stem: "题干文本",
  qtype: "单选" | "多选" | "判断" | "简答" | "论述",
  options: { A: "选项文本", B: "..." },   // 判断题可能为空对象
  answer: "D" | "AB" | "正确" | "错误" | "参考答案文本" | "",
  explanation: "解析文本",
  source: "auto" | "manual",
  page: 0,      // PDF 页码，从 1 开始；docx 为 0
  line: 0,      // PDF 页内行号；docx 为段落序号
  para: 0,      // docx 段落序号；PDF 为 0
  year: 2019,   // 题干提取到的年份，没有为 null
  topic: "第一章",  // 题干 【】 或（中文括号）里的知识点，没有为 ""
  raw: "该题原始全文"   // 用于异常日志与手动补录比对
}
```

### 错题记录 / 收藏记录
= Question 的全部字段 **+**
```js
{ wrong_count: 1, correct_streak: 0, stage: 0,
  next_review: "2026-09-17", added_at: "2026-09-17 20:10:00",
  last_wrong_at: "", last_answer_at: "" }
```

### 题目行（parser / extract 之间的中间结构）
```js
{ page: 0, line: 0, para: 0, text: "一行文本" }
```

### 存储键（IndexedDB，库名 `quiz-mobile`，version 1）
| store | keyPath | 说明 |
| --- | --- | --- |
| `banks` | `name` | 题库元信息 + 题目数组 |
| `wrong` | `[bankName, qid]` | 错题本 |
| `favorites` | `[bankName, qid]` | 收藏本 |
| `stats` | `bankName` | 统计 |
| `logs` | `[bankName, kind]` | `kind='errors'|'skipped'`，值为数组 |
| `meta` | `key` | 杂项（最近使用题库等） |

## extract.js（浏览器环境）

```js
export async function extractLines(file) -> { lines: Line[], kind: 'docx'|'pdf'|'txt', warnings: string[] }
// 抛 ExtractError（中文消息）：.doc 旧格式、扫描版 PDF、缺少依赖、文件损坏
export function isSupported(file) -> boolean
```
- docx：mammoth `extractRawText`，按段落切行（`para` = 段落序号从 1 开始，`line` 同 `para`）
- pdf：pdf.js `getTextContent()`，按 y 坐标聚合行（`page` 从 1 开始，`line` 为该页行号从 1 开始），
  全篇去空白后总长度 < 50 → 抛「扫描版 PDF 暂不支持 OCR」
- txt/md：按行读，`line` = 行号

## exporter.js（浏览器环境）

```js
export async function exportPdf(items, { title, subtitle = '', wrongInfo = false, fileName }) -> { path?, blob, pages }
export async function exportHtml(items, { title, wrongInfo = false }) -> string   // 返回完整 HTML 文本
```
中文必须不乱码（用 html2canvas 渲染 DOM 再交给 jsPDF，勿直接塞中文字符串给 jsPDF 内置字体）。
导出后：Web 环境用 `<a download>`；Capacitor 环境用 `@capacitor/filesystem` 写文件 + `@capacitor/share` 分享（可选，失败要降级到下载）。
